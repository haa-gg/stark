2. Description of Service

Stark is an open-source tabletop RPG assistant for Pathfinder 2e that searches bundled open-license rules data and optionally connects to your user-configured AI APIs, Pathbuilder 2e character exports, and Google Docs campaign notes.

3. User Responsibilities & Third-Party Accounts

  • You are responsible for ensuring you have permission to access any Google Docs URLs or character export URLs you add to Stark.
