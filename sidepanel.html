Local LLM Setup

  1. Download an Engine: Get the classic LM Studio (do not download 'Bionic') or Ollama.
  2. Download a Model: In your engine, search for and download Llama-3.1-8B-Instruct (it has the 128k context window required for Stark).
  3. Start the Server: Load the model and click "Start Server" (Ensure CORS is enabled in settings so the extension can connect).
